# หม่าล่าสามสหาย — คู่มือติดตั้งเว็บไซต์รับออเดอร์จริง

## ตั้งค่าไว้แล้ว
- ชื่อร้าน: หม่าล่าสามสหาย
- ค่าจัดส่งคงที่เริ่มต้น: 20 บาท (แก้ได้ในหลังบ้าน)
- วิธีชำระเงิน: โอนเงิน / เงินสดปลายทาง (กรณีโอน ต้องให้ร้านยืนยันเอง)
- มีเมนูตัวอย่าง 6 รายการ โปรดแก้ราคาและรายการก่อนเปิดขาย

## 1. เตรียมเซิร์ฟเวอร์
ใช้ VPS หรือบริการ Node.js hosting ที่รองรับ Node.js 20+ และมี persistent disk สำหรับฐานข้อมูล SQLite และ session; ต้องมี HTTPS และโดเมนจริง (เช่น https://your-domain.example) อย่าใช้บริการที่ลบไฟล์เมื่อ redeploy

อัปโหลดไฟล์ทั้งหมดไปยังเซิร์ฟเวอร์ จากนั้นรัน:
```bash
npm install
cp .env.example .env
```
แก้ `.env` ให้มีค่าจริงดังนี้ (อย่าเผยแพร่ไฟล์นี้):
```dotenv
PORT=3000
NODE_ENV=production
BASE_URL=https://your-domain.example
ADMIN_PASSWORD=YOUR_UNIQUE_PASSWORD_AT_LEAST_12_CHARS
SESSION_SECRET=YOUR_RANDOM_SECRET_AT_LEAST_32_CHARS
DATABASE_PATH=./data/shop.db
LINE_CHANNEL_ACCESS_TOKEN=
LINE_TO_ID=
```
ตั้ง `SESSION_SECRET` ด้วยค่าที่สุ่มอย่างปลอดภัย เช่น `openssl rand -hex 32` และเปลี่ยนรหัสผ่านตัวอย่างทันที ก่อนเปิดรับลูกค้า จากนั้นรัน `npm start` หรือใช้ process manager เพื่อให้แอปทำงานต่อเนื่อง

ตั้งค่า reverse proxy (เช่น Nginx) ให้ส่งคำขอ HTTPS ไปยัง localhost:3000 และตั้งค่า TLS certificate (เช่น Let's Encrypt) ให้ถูกต้อง ตรวจว่าเว็บไซต์โหลดได้จริงจากมือถือภายนอก

## 2. ตั้ง LINE ร้าน
1. สร้าง LINE Official Account และเปิดใช้งาน Messaging API channel ที่ LINE Developers
2. สร้าง Channel access token แล้วใส่ใน `LINE_CHANNEL_ACCESS_TOKEN`
3. ระบุ `LINE_TO_ID` เป็น **2012614449** ที่บอตสามารถ push message ได้ (ไม่ใช่ชื่อ LINE ID หรือ URL LINE)
4. เพิ่มบัญชีบอตเป็นเพื่อนหรือเชิญเข้ากลุ่มที่รองรับ และตรวจสิทธิ์/โควตาการส่งข้อความ
5. รีสตาร์ตแอป ทดลองสั่งอาหารหนึ่งออเดอร์ และตรวจสถานะ LINE ในหลังบ้านว่า `sent`

ห้ามใส่ token ใน HTML หรือส่งให้บุคคลอื่น LINE push เป็นการแจ้งเตือน ไม่ใช่ช่องทางบันทึกออเดอร์หลัก

## 3. สร้าง QR Code ของร้าน
หลังตั้ง `BASE_URL` เป็น URL เว็บไซต์จริงที่ใช้ HTTPS แล้ว เข้าหน้า `https://your-domain.example/#admin` ล็อกอินด้วยรหัสผู้ดูแล และเลื่อนถึงหัวข้อ **QR Code สำหรับลูกค้า** บันทึกรูป QR จากหน้าเว็บเพื่อพิมพ์ลงป้าย ตรวจสอบด้วยมือถืออีกเครื่องว่าพาไปหน้าเมนูจริง

**ยังไม่สามารถสร้าง QR Code ที่ใช้งานจริงได้ก่อนทราบ URL ที่เปิดใช้งานแล้ว** เพราะ QR ต้องชี้ไปยังเว็บไซต์ที่ลูกค้าเข้าถึงได้

## 4. เช็กลิสต์ก่อนเปิดร้าน
- [ ] เปลี่ยนเมนูตัวอย่างเป็นเมนูและราคาจริง
- [ ] ตรวจว่าค่าจัดส่ง 20 บาทใช้ได้กับพื้นที่บริการที่รับจริง (ระบบยังไม่ตรวจระยะทาง)
- [ ] ทดสอบสั่งจากมือถือที่ไม่ได้อยู่ในเครือข่ายร้าน
- [ ] ตรวจว่าออเดอร์บันทึกในหลังบ้านและแจ้ง LINE ได้
- [ ] ทดสอบเงินสดปลายทางและขั้นตอนยืนยันสลิปโอนด้วยคน
- [ ] ทดสอบเปลี่ยนสถานะออเดอร์
- [ ] ตั้งค่าการสำรอง SQLite และนโยบายความเป็นส่วนตัวสำหรับข้อมูลชื่อ เบอร์โทร ที่อยู่
- [ ] ตรวจ HTTPS, รหัสผ่าน และพื้นที่จัดเก็บถาวร

## ข้อจำกัดสำคัญ
ระบบนี้ยังไม่มีการตรวจสลิปอัตโนมัติ, ระบบคำนวณค่าส่งตามระยะทาง, การตรวจที่อยู่ในพื้นที่บริการ, และการอัปเดตออเดอร์แบบเรียลไทม์โดยไม่กดรีเฟรช เมนูยังใช้ไอคอนตัวอย่างแทนรูปอาหารจริง เว็บไซต์ยังไม่ได้ deploy ให้โดยอัตโนมัติ
